# UI Redesign — Warm Editorial Boutique — Implementation Plan

## Overview

Full UI-only redesign of Joyce's Closet to the "warm editorial boutique" direction decided in
`thoughts/shared/decisions/2026-07-13-ui-redesign.md`: ivory/ink/rosewood palette, Fraunces +
Work Sans, a persistent desktop sidebar (mobile: slim top bar + sticky bottom action bar),
paper-doll shuffle canvas with quiet rail chrome, CSS-only swap/cascade animations, restyled
Outfits page, and a daily rotating quote. **Zero behavior changes** — shuffle logic, stores,
persistence, outfit repair, and saving/deleting are untouched; all 63 existing tests keep
passing unmodified.

## Current State Analysis

- **Tokens**: Tailwind 4 `@theme` in `src/index.css:3-13` — pastel palette (`blush`, `blush-light`, `rose`, `periwinkle`, `mist`, `cream`) + Playfair Display/Montserrat.
- **Fonts**: Google Fonts `<link>` in `index.html:8-13`.
- **Shell**: `src/components/Layout.tsx` — blush top bar, "Home"/"Outfits" links, centered `max-w-5xl` main.
- **Canvas**: `src/features/shuffle/ShufflePage.tsx` — periwinkle headline, Shuffle All / Save Outfit buttons on the canvas, inline naming form that reflows the page (`ShufflePage.tsx:73-107`), even 2-col rail grid (`ShufflePage.tsx:135`), `SIZE` map at `ShufflePage.tsx:10-14`, dormant dress toggle (`ShufflePage.tsx:110-133`).
- **Rails**: `src/components/Rail.tsx` — big always-on periwinkle `‹ ›` text arrows (`Rail.tsx:18-20`), labeled "Shuffle X" pill per rail (`Rail.tsx:101-107`), swipe threshold at `Rail.tsx:16`, wrap-around stepping, dashed "No {label}" empty slot.
- **Outfits**: `src/features/outfits/OutfitsPage.tsx` + `OutfitCard.tsx` — blush-bordered white cards, always-visible `×` delete (`OutfitCard.tsx:82-89`), mini paper-doll preview (`OutfitCard.tsx:32-70`).
- **State**: Zustand stores are global (`useShuffleStore`, `useOutfitsStore`) — any component can call `shuffleAll`/`saveOutfit`, so moving actions into the sidebar is pure UI.
- **Naming state**: `naming`/`name`/`justSaved` + 1.8s timer live in `ShufflePage.tsx:25-33` and must move with the Save button.
- **Correction to the decisions doc**: it says "seeded RNG exists in `src/lib/rng.ts`" — it does **not**. `rng.ts:1-5` is only a `Math.random`-compatible type alias used by shuffle. The daily quote picker needs its own tiny date-hash (below); `rng.ts` stays untouched.
- **Baseline**: `npm test` → 4 files, 63 tests, all passing. `dist/` is committed build output regenerated by `npm run build`.

## Desired End State

- App background is warm ivory; all text is ink; rosewood is the single accent; periwinkle/mist/cream are gone from the codebase.
- Desktop: left sidebar (brand → Today/Outfits → divider → action block on Today only → quote footer); canvas holds only headline + paper-doll rails.
- Mobile: slim top bar (brand + nav); sticky bottom action bar on Today; paired-rows paper doll (jacket|top, bottom, shoes|accessory); swipe still works.
- Save flow is a popover anchored to the Save button; canvas never reflows; default-name prefill and "Saved ✓" preserved.
- Item swaps animate in; Shuffle All cascades the rails with a stagger.
- Outfits page cards are soft rectangles with hairline borders and a ghost delete.
- A daily-deterministic quote (mixed real/invented) renders in the sidebar footer, editable in one file.

**Verify by**: `npm run lint && npm run typecheck && npm test` all pass; manual checklist per phase below.

### Key Discoveries

- Stores are global Zustand — sidebar actions need no prop-drilling or logic changes (`useShuffleStore.ts:51`, `useOutfitsStore`).
- Decision 13 says **stores untouched**, so the Shuffle-All cascade signal cannot live in `useShuffleStore` — it gets its own tiny UI-only store (Phase 3).
- Tailwind 4 supports `@keyframes` + `--animate-*` tokens inside `@theme` — animations need no new dependency.
- React keyed remount (`key={itemId}`) is the CSS-only trigger for swap animations; including a cascade tick in the key re-animates all rails on Shuffle All even when an item repeats.
- Old and new tokens can coexist in `@theme`, enabling phase-by-phase migration with a working app at every step.

## What We're NOT Doing

- Dark mode.
- Any behavior/logic changes, new features, or closet-content changes (`shuffle.ts`, `outfit.ts`, `closet.ts`, `naming.ts`, `localStorageStore.ts`, all stores: untouched).
- Route/page transitions or ambient decoration (animation tier 3).
- New dependencies (no framer-motion, no icon packs — inline SVG only).
- Enabling the dress feature (toggle stays dormant but functional and restyled).
- Favicon / meta / PWA polish.
- Editing anything in `dist/` by hand (rebuilt via `npm run build` in Phase 5).
- Quote on mobile — per Decisions 5/12 the quote is the desktop sidebar footer; mobile has no quote surface.

## Implementation Approach

Migrate in five phases, each leaving the app fully working. Phase 1 **adds** the new tokens
alongside the old ones (redefining `--color-blush` to the new tint value — unmigrated
components shift slightly pinker-neutral for the duration, which is acceptable). Phases 2–4
migrate the shell, canvas, and Outfits page. Phase 5 deletes the legacy tokens, greps for
stragglers, and rebuilds `dist/`.

Shared visual vocabulary used throughout (Decision 9):

- **Primary pill** (Shuffle All only): `bg-rosewood text-ivory rounded-full font-medium shadow-sm hover:bg-rosewood/90 active:scale-[0.98] transition cursor-pointer`
- **Secondary pill** (Save Outfit, load/wear CTA): `border border-rosewood/40 text-rosewood rounded-full hover:bg-blush/60 active:scale-[0.98] transition cursor-pointer`
- **Tertiary ghost icon** (per-rail shuffle, arrows, delete, cancel): `rounded-full text-ink/40 hover:text-rosewood hover:bg-blush/60 transition cursor-pointer`
- **Surfaces** (cards, popover, empty slots): `rounded-2xl border border-ink/10 bg-white` (or `bg-ivory` for the popover), soft shadows only.
- **Hairlines**: `border-ink/10`. **Muted text**: `text-ink/55` (or `/40` for whispers). No dedicated tokens needed — opacity modifiers on `ink`.

export interface Quote {
  text: string;
  /** Real fashion-icon quotes get a short attribution; invented one-liners carry none. */
  by?: string;
}

/**
 * The daily quote pool. Edit freely — this file is the only place quotes live.
 * Order matters only for which day gets which quote.
 */
export const QUOTES: Quote[] = [
  { text: "Fashions fade, style is eternal.", by: "Yves Saint Laurent" },
  { text: "Shuffle until it feels like you." },
  {
    text: "Dress shabbily and they remember the dress; dress impeccably and they remember the woman.",
    by: "Coco Chanel",
  },
  { text: "Trust the shuffle." },
  { text: "Style is a way to say who you are without having to speak.", by: "Rachel Zoe" },
  { text: "Great outfits begin with a little chaos." },
  { text: "Give a girl the right shoes, and she can conquer the world.", by: "Marilyn Monroe" },
  { text: "The right outfit was in the closet all along." },
  { text: "People will stare. Make it worth their while.", by: "Harry Winston" },
  { text: "Wear the thing you keep saving for later." },
  { text: "Elegance is refusal.", by: "Coco Chanel" },
  { text: "Today's forecast: fully dressed, with a chance of compliments." },
  { text: "More is more and less is a bore.", by: "Iris Apfel" },
  { text: "An outfit a day keeps the “nothing to wear” away." },
];

/** Same quote all (local) day, next quote tomorrow — local-midnight day count wrapped onto the list. */
export function quoteOfTheDay(date: Date = new Date()): Quote {
  const localDays = Math.floor(
    (date.getTime() - date.getTimezoneOffset() * 60_000) / 86_400_000,
  );
  return QUOTES[localDays % QUOTES.length];
}
```

import { QUOTES, quoteOfTheDay } from "./quotes";

describe("quoteOfTheDay", () => {
  it("returns the same quote for any two times on the same day", () => {
    expect(quoteOfTheDay(new Date(2026, 6, 13, 0, 1))).toBe(

import { create } from "zustand";

/** UI-only pulse: Shuffle All bumps the tick so every rail remounts and staggers in. */
interface CascadeState {
  tick: number;
  bump: () => void;
}

export const useCascade = create<CascadeState>()((set) => ({
  tick: 0,
  bump: () => set((state) => ({ tick: state.tick + 1 })),
}));
```

const lastTick = useRef(cascadeTick);
const cascading = cascadeTick !== lastTick.current;
useEffect(() => {
  lastTick.current = cascadeTick;
});

// inside the swipe frame:
<div
  key={`${active?.id ?? "none"}:${cascadeTick ?? 0}`}
  className="animate-rail-in flex h-full w-full items-center justify-center"

## Deviations Made During Implementation

Three places where the codebase forced a change to the plan's literal code (intent preserved in
all three):

1. **`quoteOfTheDay` index guard** (Phase 1). The repo compiles with
   `noUncheckedIndexedAccess: true`, so `QUOTES[i]` is typed `Quote | undefined` and the plan's
   `return QUOTES[localDays % QUOTES.length]` failed `npm run typecheck`. Guarded with a throw on
   the impossible index, matching the existing `at()` idiom in `shuffle.ts:14-21`.

2. **Rail cascade delay: state, not a ref** (Phase 3). The plan's `useRef` + read-during-render
   formulation fails lint — `eslint-plugin-react-hooks` v7 `recommended-latest` enables the
   React-Compiler rule `react-hooks/refs` ("Cannot access refs during render"). Replaced with a
   `frame` state object (`{key, tick, delay}`) adjusted during render, which additionally fixes the
   risk the plan itself flagged: the delay is now frozen for the mounted frame's lifetime, so a
   re-render mid-cascade cannot rewrite `animation-delay` on a still-animating element.
   Also added `animation-delay: 0ms !important` to the reduced-motion block — without it a
   staggered rail would hold invisible (fill-mode `both`) for up to 280ms before snapping in.

3. **Card delete on touch tablets** (Phase 4). Tailwind compiles `group-hover` inside
   `@media (hover:hover)`, so the plan's `md:opacity-0` would leave the delete button permanently
   invisible on a touch device wider than `md` (e.g. an iPad), breaking the decisions doc's "must
   stay reachable on touch". Hiding is now gated on a hover-capable pointer:
   `md:pointer-fine:opacity-0` (verified in the built CSS as
   `@media (width>=48rem){@media (pointer:fine){…}}`).
